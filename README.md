# issoaquilo
Projeto avaliação 3 - Prática de Programação Web / Faculdade Municipal de Palhoça

Projeto ISSOAQUILO: Site de quiz interativo de comparação entre temas e curiosidades específicas do Brasil. O usuário deverá escolher entre as duas informações apresentadas e descobrir qual delas possui o MAIOR VALOR.

Atualmente o site contém 3 temas diferentes para se jogar o minigame: 

1. Tempo
Qual dos dois durou mais tempo?

Exemplos:
- Tempo de construção do Cristo Redentor × Duração da Era Vargas.
- Rogério Ceni como goleiro profissional × Tempo de exibição dos Trapalhões na televisão.

2. Quantidade/Trivia
Qual dos dois possui o maior número?

Exemplos:
- Número de Copas do Mundo disputadas pelo Brasil × Número de presidentes que o Brasil já teve.
- Número de Oscars conquistados pelo Brasil × Número de feriados nacionais oficiais.

3. Mais Streams
Qual artista possui mais ouvintes mensais no Spotify?

Exemplos:
- Anitta × Jão.
- Matuê × Exaltasamba.

O 4º minigame ainda não foi finalizado. Mas ele seguirá a mesma lógica dos demais jogos acima.

O projeto visa não só criar diversão e competitividade ao jogador, como também exercitar sua mente e atribuir novos conhecimentos e curiosidades sobre o território brasileiro e sua cultura.
